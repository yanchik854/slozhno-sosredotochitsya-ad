# Проект «Сложно сосредоточиться»

Учебный проект, выполненный в рамках обучения на Яндекс Практикуме.

Репозиторий: https://github.com/yanchik854/slozhno-sosredotochitsya-ad

### Технологии:
* HTML5
* CSS3 (Flexbox, Grid, CSS-переменные)
* JavaScript

### Функционал:
* Адаптивная верстка (мобильные, планшеты, десктоп).
* Переключение светлой и темной темы.
